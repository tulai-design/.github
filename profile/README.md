# 图来设计 · Tulai Design

**小而认真的工具工作室。**

围绕创作与日常，做可以直接使用的工具，也维护它们共用的 AI 基础能力。

[图来设计](https://tulai.design/) · [Joshua / ROYIANS](https://github.com/ROYIANS)

## 正在做的工具

### [搭搭](https://github.com/tulai-design/dada-home)

用 AI 搭建自己的个人主页。把订阅、待办、书签与日常信息放在一起，也可以让 AI 制作小工具、调整主题和页面。数据本地优先，AI 服务由你选择。

[打开搭搭 ↗](https://dada.tulai.design/) · [查看源码](https://github.com/tulai-design/dada-home)

### [默默 · Momoki](https://github.com/tulai-design/momoki)

本地优先的 AI 创作工作室。把影视分镜、素材、音频制作和音乐生成放进同一个项目，支持浏览器和桌面端，连接你自己的模型服务。

[打开工作室 ↗](https://momoki.tulai.design/) · [查看源码](https://github.com/tulai-design/momoki) · [桌面版本](https://github.com/tulai-design/momoki/releases)

## 共用的基础能力

### [AI Platform](https://github.com/tulai-design/ai-platform)

为产品提供共用的 Agent 执行、工具权限、上下文管理和模型协议适配。以独立的 TypeScript / ESM 包发布，支持 OpenAI Chat Completions、Responses 与 Anthropic Messages。

- [`@tulai-design/agent-core`](https://www.npmjs.com/package/@tulai-design/agent-core) — Agent 执行与工具契约。
- [`@tulai-design/agent-providers`](https://www.npmjs.com/package/@tulai-design/agent-providers) — 模型协议与流式传输。
